OrganicQuiz

OrganicQuiz is a simple Python quiz for learning organic chemistry.

Features

* Three questions about organic functional groups.
* Automatic answer correction.
* Final score calculation.

Topics Covered

* Alcohol
* Carboxylic acid
* Aldehyde

How to Run

1. Open main.py in a Python environment.
2. Run the program.
3. Answer the three questions.
4. Check your final score.
